KwadratowyBohater (dawniej LiniowyBohater) to gra stworzona na przełomie 2023/2024 w ramach nauki pythona.
Z racji kodu rodem z talerza ze spaghetti nie widzę sensu dalszej aktualizaji owej gry.
Ostatnia aktualizacja miała miejsce 05.01.2025, wprowadziła całkowity rework przeciwników, systemu walki, dodanie bossa oraz statystyki w osobnym oknie.
(W grze występuje niecenzuralny język, obrażanie gracza, podteksty na tle seksualnym oraz inne (nie)śmieszne żarty dodane przez moich kolegów.)
